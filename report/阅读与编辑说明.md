# MiniDEX 实验报告 · 排版精修版

这一版只调整**实验报告文字和阅读样式**，不更改任何 Solidity、前端或历史交易记录。

## 直接编辑

在 VS Code 打开 `实验报告.md`，按 `Ctrl+Shift+V` 预览。报告使用常规 Markdown 语法，在 GitHub 上也能阅读；在 GitHub 上字体由网站决定，无法由 `.md` 文件强制指定。

## VS Code 预览字体与间距

本包包含 `docs/report-style.css`。要让 VS Code 的 Markdown 预览应用此样式，建议把整个ZIP解压到项目根目录的 `report/` 子文件夹。在项目的 `.vscode/settings.json` 中添加下面这一项（如果已有 JSON 设置，只合并此键，不要覆盖整个文件）：

```json
{
  "markdown.styles": ["report/docs/report-style.css"]
}
```

保存后重新打开 Markdown 预览。如果不想修改 VS Code 设置，可直接打开本包的 `实验报告_阅读预览.html`，浏览器会应用相同的字体和布局。

样式优先使用系统常见的中文无衬线字体：Noto Sans CJK SC、微软雅黑、苹方、思源黑体；没有任何外部字体下载依赖。

## 放入当前项目

推荐放在仓库内的 `report/` 目录。解压后应为 `report/实验报告.md`、`report/docs/images/`、`report/docs/figures/`、`report/docs/report-style.css` 和 `report/evidence/reports/`。这版不覆盖项目根目录README、前端或Solidity源码。如果你想在仓库首页展示报告，可以手工在根README加入 `[实验报告](report/实验报告.md)`。

## 仍需亲自核对

- 在报告顶部填写姓名、学号与公开GitHub地址；删掉不适用的项目。  
- 截图说明应与你录制视频时的实时状态一致。历史图片可保留，但不能写成刚刚重新发送的交易。  
- 最新视觉界面 V2 的前端单元测试、类型检查和构建还需在 Windows 上跑一次最终回归。  
- 录制 1–2 分钟视频并压缩，向课件指定邮箱提交仓库链接与视频。  

**备注：** 本包不包含运行中的Ganache数据库，Hardhat临时测试结果也不代表Ganache历史交易。
